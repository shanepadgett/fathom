# Standards Maintenance

For editing standards or `AGENTS.md` rules. Skip when merely following them.

- Keep `AGENTS.md` small; put domain rules in `docs/standards/`.
- Give each standard a clear scope and matching read/skip entry in `AGENTS.md`.
  Reading source material alone does not trigger maintenance rules.
- Keep rules in one place. Link instead of duplicating; no recursive reading.
- Add guidance for existing needs. Preserve authorization boundaries.
- Check links and scope agreement. Repo-local Codex lifecycle hooks apply
  Markdown fixes automatically at turn completion.
