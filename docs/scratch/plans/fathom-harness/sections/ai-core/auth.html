Auth

Provider-owned. Resolved by the Models collection on each stream. Agent-core never touches this layer — the host builds Models with a CredentialStore and calls login / logout / getAuth.

Types and helpers: packages/ai/src/auth/ (types.ts, resolve.ts, credential-store.ts, helpers.ts, context.ts). OAuth flows: packages/ai/src/auth/oauth/.

Types

read, list, modify (serialized read-modify-write), delete. One credential per provider id. Default: InMemoryCredentialStore — apps inject persistence. { type: "api_key"; key?; env? } or { type: "oauth"; access; refresh; expires }. env(name), fileExists(path). Default reads process.env / Node fs. Resolved request auth: apiKey?, headers?, baseUrl?. auth + optional source label for UI ("OAuth", "OPENAI_API_KEY", …). Host callbacks for login: prompt() (text/secret/select/manual_code), notify() (info/auth_url/device_code/progress). Optional apiKey: ApiKeyAuth and/or oauth: OAuthAuth on each provider. login, refresh, toAuth. Codes include "auth" and "oauth".

Models auth API

Runs provider login; persists credential via the store. Deletes stored credential. Resolve without streaming; refreshes OAuth if needed.

Resolve order

options.apiKey when the provider supports api-key auth. OAuth: refresh if expiring within five minutes (under modify lock), then toAuth. API key: provider resolve. Env / files only if nothing is stored. Failed refresh does not fall back to env.

Per provider

Env: ANTHROPIC_API_KEY, ANTHROPIC_OAUTH_TOKEN, ANTHROPIC_AUTH_TOKEN (Bearer). OAuth: Claude Pro/Max, PKCE, loopback :53692 or paste redirect. Refresh rotates tokens. OPENAI_API_KEY only. ChatGPT Plus/Pro. Browser PKCE (localhost:1455) or device code. Refresh rotates tokens. No platform API key path. XAI_API_KEY. OAuth: device code against auth.x.ai (no local HTTP server). Refresh supported. OPENROUTER_API_KEY. OAuth PKCE mints a permanent user key stored as type oauth; refresh is a no-op.

OAuth implementations load lazily (lazyOAuth + auth/oauth/load.ts). Anthropic, Codex, and OpenRouter use Node http callback servers — Deno needs a compat check or the manual paste path. xAI is fetch + device poll only.

@earendil-works/pi-ai/oauth is type-only compatibility for extensions. Runtime login is models.login(...).
