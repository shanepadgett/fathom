Map

Chat and Desktop are the two products on top. Both call the same Agent Runtime. Runtime talks to models only through AI Core — the one Pi package we use.

Runtime runs with no UI. UIs send commands and listen for events. That stops web and desktop from inventing their own agent rules. Multiplayer chat is web only. Desktop is where plugins and a richer local UI live.

We do not use Pi’s Agent, AgentHarness, or pi-agent-core. We build the loop. Pin Pi AI at 0.83.0 when it becomes a real dependency. When the two markdown notes disagree, owned-agent-runtime-plan.md wins — except the Agent dependency, which this plan drops. Product and host notes still come from agent-runtime-and-clients.md where they do not conflict.
