Goals

The desktop coding app and the enterprise web chat share one agent runtime. Same session model. Same rule that only one run is active at a time. Same tools and hooks. The products differ in how they start a run and what UI they show — not by shipping a second agent engine.

We own the product rules and the model/tool loop: sessions, tools, when history gets summarized, permissions, how a web @mention becomes a run, and how turns run. We are not using Pi’s Agent or AgentHarness.

We still use Pi AI. Talking to Anthropic, OpenAI, Gemini, and the rest is messy. Provider protocols, streaming, and shared message types are work Pi already did. We should not rebuild that.

Desktop is where plugins and a richer UI matter. Web chat stays simple and closed. Web code can still be modular. Customers do not install plugins there.

On desktop, plugins may add panels, custom tool views, layout presets, and embedded editors. That is as far as we go. A plugin cannot replace the whole app shell.
