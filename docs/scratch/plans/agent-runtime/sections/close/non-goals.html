Non-goals

We are not adopting Pi’s Agent, agentLoop helpers, or AgentHarness. Provider I/O comes from Pi AI. The model/tool loop is ours.

A plugin cannot replace the entire desktop UI. Enterprise web chat does not get a customer plugin marketplace. The long human thread is not what we send the model unless it first goes through an agent session. Multiple runs at once on one session stay out until product has a clear rule for that.

We are not building two agent engines. Desktop and chat may differ in tools, permissions, and UI. They share session rules, the one-run lock, event shape, and how data is saved.
