What we own above AI Core

Pi AI stops at providers and streams. From the first turn of a run upward, we own the runtime.

Provider I/O and streaming
Normalized message shapes
Model metadata
Usage and stop reasons
Credential lookup hooks
Execution loop (turns, tools, steer, cancel)
Tools and tool registry
Folder trust and command permissions
Saved sessions and branches
SQLite schema and migrations
Prompt building and history summaries
Crash recovery
Model selection policy
Project instructions
Runtime event bus and host commands
Extension contribution APIs (backend)

Hosts sit above this. They may add product rules (thread mapping, desktop layout, SSO). They should not invent a second idea of what a session is. If desktop and web disagree about sessions, the bug is in the runtime or the host contract.
