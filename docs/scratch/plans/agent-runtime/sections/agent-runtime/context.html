Context

Saved history and “what we send the model” are different. SQLite holds the full history. A separate step builds the prompt: pick the branch, add summaries, pull in extra project context, drop noise, and stay under the token limit. Only then does the loop send messages through AI Core.

Normalized messages through AI Core

Building context is a normal step before each model call. The loop asks our context code for the next prompt. We do not hang that work on a third-party agent hook.

// Intent — our loop calls our context code each turn const messages = await contextManager.buildModelContext({ sessionId, branchId, signal, }); await loop.requestModel({ messages, model, tools, signal });

That code can pick rows from the active branch, insert saved summaries, pull project files or other context, shrink huge tool results, skip UI-only noise, respect each provider’s size limits, and keep recent turns exact while older work is summarized.

When we trim history, write a real summary record: what it covered, which method and version made it, which model, what instructions, token use, and the summary text. Do not silently rewrite or delete the old rows.

Between turns in one run, the loop may rebuild context, switch model, or change thinking settings when that has to happen before the next provider request. Anything we need to keep still goes through the runtime and the database.
