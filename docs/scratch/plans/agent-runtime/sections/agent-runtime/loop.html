Execution loop

We build the model/tool loop ourselves. No @earendil-works/pi-agent-core, no Pi Agent, no AgentHarness. Pi AI handles providers. Turns, tools, queues, and finishing a run are our code.

Earlier notes assumed we would reuse Pi’s low-level Agent. That is out. The loop needs to fit our sessions, extension hooks, permissions, and events. Building it costs time up front. Fighting someone else’s loop later costs more.
