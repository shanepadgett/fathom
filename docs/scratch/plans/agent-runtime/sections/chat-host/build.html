Build chat

Chat comes after the headless runtime exists and desktop has proven a single client can drive it. Chat adds thread mapping and multiplayer product rules on top of session behavior that should already be stable.

Done for the bridge when a test can open a thread, @mention the agent twice, reuse one session, refuse a second concurrent run, and recover a retried client call without double-starting work.

Done for the first product slice when a person can read the human thread, see the agent reply in place, and the model only saw the trimmed session plus the latest slice.
