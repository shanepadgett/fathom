Host duties

Chat Host connects multiplayer product code to Agent Runtime. Keep it small. If it grows a second session system, something went wrong.

Chat Host owns initiative membership, thread permissions, @mention parsing, notifications, and typing indicators. Runtime owns session memory, tools, and the model loop. Human conversation stays in chat storage. Agent working memory stays in runtime SQLite.

The long human thread is never what we send the model unless it first goes through an agent session as a deliberate slice.
