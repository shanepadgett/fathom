Chat Host — product

Online chat is enterprise multiplayer AI chat. People work inside initiatives and talk in threads, a bit like Slack. Humans talk to each other. The named agent only joins when someone @mentions it.

What people see is threads, members, permissions, and notifications. That is normal product code, not part of the agent loop. Under the thread UI sits a host that maps work onto Agent Runtime.

Chat Host is closed. No customer plugin marketplace. No loading extensions from disk. Tools and modules are chosen when we deploy. The UI stays simple. Some agent features (like a todo list the model uses) may run even when the chat UI does not show them.

Goal is one shared runtime with desktop, not a second agent engine for chat. If chat needs different tools or tighter permissions, that is host config on the same runtime.
