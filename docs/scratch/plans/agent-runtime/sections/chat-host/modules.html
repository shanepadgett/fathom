Modules

Chat Host can use runtime modules. It does not load extensions from folders at runtime. It does not get desktop UI plugins. Internal packages are normal imports chosen at deploy.

Chat Host Desktop Host
Runtime modules Yes, chosen at deploy Yes
Load extensions from disk No Yes (repo + user machine)
UI plugins No Yes
Same todo runtime module Yes, often hidden Yes, panel optional

That split matters for packaging. A module that only needs tools and session state can ship on both products. A module that needs a side panel is desktop only. Do not pull desktop UI APIs into the chat deploy just because the package exists in the monorepo.

Prefer a locked tool policy on web. Full desktop tool packs stay on desktop until product explicitly opens them for chat.
